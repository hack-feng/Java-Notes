## 3. 配置大模型

OpenClaw支持多种模型接入。如果你有自己的API Key（比如腾讯云Coding Plan、阿里云Coding Plan等），可以直接配置。

![image-20260311105117151](https://image.xiaoxiaofeng.site/blog/image/image-20260311105117151.png?xiaoxiaofeng)

如果找不到你需要的渠道，可以自定义配置，这里以讯飞Coding Plan为例，在OpenClaw中新增自定义模型，填入以下JSON配置：

```json
{
  "provider": "astroncodingplan",
  "base_url": "https://maas-coding-api.cn-huabei-1.xf-yun.com/v2",
  "api": "openai-completions",
  "api_key": "请在讯飞星辰MaaS平台 套餐订阅 页面中获取",
  "model": {
    "id": "astron-code-latest",
    "name": "astron-code-latest"
  }
}
```

![image-20260311105531385](https://image.xiaoxiaofeng.site/blog/image/image-20260311105531385.png?xiaoxiaofeng)

保存后，模型就配置好了！

![image-20260311131904514](https://image.xiaoxiaofeng.site/blog/image/image-20260311131904514.png?xiaoxiaofeng)

关于如何选择模型，可以参考下面这个表，token价格肯定会打下来的，可以找个感兴趣的先体验（**一定要注册新用户去买，便宜很多**）。

![image-20260311103642059](https://image.xiaoxiaofeng.site/blog/image/image-20260311103642059.png?xiaoxiaofeng)

## 4. 配置连接通道

OpenClaw可以接入飞书、QQ、钉钉等平台（支持多个平台同时使用）。腾讯云集成了飞书创建机器人，可以扫码授权，一键配置超方便，也可以自己手动配置。

选择飞书通道，点击「快捷配置」→「前往授权」，会弹出一个二维码。

![image-20260311111651831](https://image.xiaoxiaofeng.site/blog/image/image-20260311111651831.png?xiaoxiaofeng)

用飞书手机端扫码，确认授权。授权成功后，你会看到飞书开放平台里多了一个应用。

https://open.feishu.cn/app

**看到那个穿着龙虾外套的企鹅了吗？** 没错，这就是腾讯云自动为你创建的OpenClaw机器人！

![image-20260311111831628](https://image.xiaoxiaofeng.site/blog/image/image-20260311111831628.png?xiaoxiaofeng)

当然我们也可以去飞书开放平台去修改它的名称、头像、权限等信息。
