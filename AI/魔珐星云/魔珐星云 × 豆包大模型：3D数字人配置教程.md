## 二、获取豆包大模型（火山引擎）

### 2.1 登录火山引擎

- 访问火山引擎官网：https://www.volcengine.com/
- 已有账号直接登录，无账号请先注册

![火山引擎登录](https://image.xiaoxiaofeng.site/blog/image/image-20260414120907189.png?xiaoxiaofeng)

### 2.2 进入 ARK 控制台

登录后访问：https://console.volcengine.com/ark

### 2.3 创建 API Key

- 在左侧菜单中找到 **【API KEY 管理】**
- 点击【创建 API Key】，生成后**务必保存**

![API KEY 管理](https://image.xiaoxiaofeng.site/blog/image/image-20260414130935130.png?xiaoxiaofeng)

### 2.4 选择模型并获取接入信息

1. 进入【模型广场】，选择你想使用的模型（如 GLM-4.7、DeepSeek 等）

![模型广场](https://image.xiaoxiaofeng.site/blog/image/image-20260414132711658.png?xiaoxiaofeng)

2. 点击模型卡片右上角的 **【API 接入】**

![API 接入](https://image.xiaoxiaofeng.site/blog/image/image-20260414132733892.png?xiaoxiaofeng)

3. 选择刚刚创建的 API Key
4. 开通所需模型（免费额度请留意）
5. 复制该模型对应的 **Model ID**（例如 `glm-4-7-251222`）

![获取模型名称](https://image.xiaoxiaofeng.site/blog/image/image-20260414132855089.png?xiaoxiaofeng)

> ⚠️ 注意各模型的**免费额度限制**，避免超额产生费用。

## 三、本地配置与体验

### 3.1 填入配置信息

在工具界面中填入以下信息：

| 配置项         | 说明         | 获取位置                |
| -------------- | ------------ | ----------------------- |
| 魔珐 AppKey    | 应用密钥     | 魔珐星云应用管理        |
| 魔珐 AppSecret | 应用密钥     | 魔珐星云应用管理        |
| 豆包 API Key   | 火山引擎密钥 | 火山 ARK API KEY 管理   |
| 豆包 Model ID  | 模型标识     | 火山模型广场 → API 接入 |

![配置界面](https://image.xiaoxiaofeng.site/blog/image/image-20260414133140894.png?xiaoxiaofeng)

> 🔒 配置信息仅保存在浏览器的 `localStorage` 中，**不会上传到任何服务器**，请放心使用。

### 3.2 开始体验

配置完成后，即可与数字人进行对话交互。

![体验界面](https://image.xiaoxiaofeng.site/blog/image/image-20260414133252687.png?xiaoxiaofeng)

## 常见问题（FAQ）

**Q：邀请码失效怎么办？** 
A：请检查是否已被使用，或联系魔珐官方获取新邀请码。

**Q：豆包模型调用返回错误？** 
A：请确认 API Key 和 Model ID 是否正确，以及账户内是否有足够余额/免费额度。

**Q：数字人没有声音或动画？** 
A：请检查浏览器是否允许麦克风权限，并确保网络连接稳定。
